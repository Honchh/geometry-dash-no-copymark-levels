gd-clean-levels

A curated archive of Geometry Dash levels exported with no C-mark (copy indicator) and stripped/clear metadata.

When levels are copied in-game or exported directly from save files, Geometry Dash retains revision history, original creator IDs, local song paths, and internal tracking tags. Every level in this repository has been sanitized to ensure:
- **No (C) Mark:** Original copy flags and parent level IDs are removed.
- **Clean Metadata:** Unnecessary revision tags, local timestamps, and leftover editor data are stripped.
- **Ready to Import:** Standard `.gmd` / `.gmd2` files compatible with GDShare and Geode

## How to Use
1. Download the desired `.gmd` or `.gmd2` file.
2. Open **Geometry Dash**.
3. Go to your **Create** tab, click the **Import** button, and select the downloaded file.

Note : If the "How to Use" isnt working, its probably outdated, Tutorials for newer versions will be on Youtube and this Project is still Developing. Expect bugs/Unusable/corrupted files.
